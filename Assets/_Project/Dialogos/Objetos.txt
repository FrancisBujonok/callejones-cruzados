# Lo que piensa el personaje al mirar un objeto con E (Paso 28).
#
# Formato: clave | cuando | linea
#   clave:    el tipo de objeto (tiene que ser igual a la del componente Inspectable).
#   cuando:   calma    = lo normal.
#             miedo    = con el miedo en 50 o mas.
#             otra_vez = si ya miraste ese tipo de objeto antes (sale 6 de cada 10 veces).
#   linea:    lo que dice. Corta: entra en dos renglones de pantalla.
#
# Se elige una al azar entre las que corresponden, sin repetir la ultima.
# Para agregar una linea, copia un renglon y cambia el texto. Para sacar una, borrala
# o ponele # adelante. Los cambios se ven la proxima vez que le des a Play.
